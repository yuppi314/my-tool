# メールリストの保管と毎月の吉方位メール(無料・Googleアカウントだけで動きます)

Renderの無料プランは再起動のたびにサーバーのデータが消えるため、メール登録はGoogleスプレッドシートにも保存します。
同じ仕組みで、吉方位の月が切り替わる(節入り)たびに、登録者へ「今月の吉方位」をGmailから自動で送ります。

## 設定手順(15分ほど)

1. Googleドライブで新しいスプレッドシートを作る(名前は「吉方位メールリスト」など)。
2. メニューの「拡張機能」→「Apps Script」を開く。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの `Code.gs` の中身を貼り付けて保存する。
4. 左の歯車「プロジェクトの設定」→ 一番下の「スクリプト プロパティ」で、次の3つを追加する。

   | プロパティ | 値 |
   |---|---|
   | `SECRET` | 推測されにくい長い文字列(例: パスワード生成ツールで作った40文字ほど) |
   | `SITE_URL` | 診断サイトのURL(例: `https://kippou-mile-travel.onrender.com`、最後の `/` は付けない) |
   | `SENDER_NAME` | メールの差出人名(屋号) |

5. エディタ上部の関数の選択で `setup` を選んで「実行」する。初回はGoogleの許可画面が出るので、自分のアカウントで許可する
   (「このアプリは確認されていません」と出たら「詳細」→「(安全でないページ)に移動」で進めます。自分で作ったスクリプトなので問題ありません)。
   これで `leads` シートと、毎朝9時台に配信をチェックするトリガーができます。
6. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」を選び、
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**

   にして「デプロイ」。表示された「ウェブアプリのURL」(`https://script.google.com/macros/s/.../exec`)をコピーする。
7. Renderの診断サイトの「Environment」に次の2つを追加して保存する。

   | 環境変数 | 値 |
   |---|---|
   | `LEADS_WEBHOOK_URL` | 手順6のウェブアプリのURL |
   | `LEADS_WEBHOOK_SECRET` | 手順4の `SECRET` と同じ文字列 |

8. 診断サイトでメールアドレスを入れて診断し、スプレッドシートの `leads` シートに1行増えれば完了です。

## 動き方

- 登録した月は結果ページで今月の吉方位を見ているので、メールは**次の節入り(吉方位の月の切り替わり、毎月4〜8日ごろ)から**届きます。
- 届くメールには、今月の最大吉方・おすすめ旅先3件・結果ページへのリンク・配信停止リンクが入ります。
- 配信停止リンクを押してボタンを押すと、シートの「状態」が「配信停止」になり、以後は送りません。手でシートの状態を書き換えても同じです。
- Gmailで送れるのは**1日100通まで**(Google Workspaceなら1,500通)です。上限を超えた分は翌朝の実行で続きから送ります。
  登録者が数千人を超えたら、Brevo・配配メールなどのメール配信サービスへの移行を検討してください(シートをCSVで書き出して移せます)。

## コードを更新したとき

`Code.gs` を貼り替えたら、「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」で更新してください
(URLは変わりません)。新しくデプロイし直すとURLが変わるので、その場合は `LEADS_WEBHOOK_URL` も更新が必要です。
