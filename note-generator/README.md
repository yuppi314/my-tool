# note.com有料記事 自動生成ツール

テーマを入力すると、note.comで販売する有料記事の下書き(タイトル案・見出し構成・本文)を自動生成する個人利用ツールです。
詳細な要件は要件提示書を参照してください(実装の背景・スコープ・KPIなど)。

## セットアップ

```bash
cd note-generator
npm install
cp .env.example .env
```

`.env` に Claude API キーを設定してください。

```
ANTHROPIC_API_KEY=sk-ant-xxxxx
```

## 起動

```bash
npm start
```

`http://localhost:3100` にアクセスするとフォームが表示されます。

## 使い方

1. テーマ・キーワードを入力(必須)
2. 必要に応じてターゲット読者・トーン・想定文字数・参考資料を入力
3. 「下書きを生成する」を押すとタイトル案と記事本文(無料部分/有料部分)が生成される
4. 「Markdownをコピー」でそのままnote.comの編集画面に貼り付け可能
5. 生成した記事は履歴として残り、いつでも再表示できる

## データの保存先

- `data/index.json` … 生成履歴のメタデータ(テーマ・タイトル案・日時など)
- `data/articles/*.md` … 生成された記事本文(Markdown)

いずれもローカル保存のみで、Gitの管理対象外(`.gitignore`済み)です。
