# 原稿の取り込み記録

Googleドライブ `kodomo-nisa-pages/` から取り込んだ漫画40ファイルを、
シナリオ (`../scenario.txt`) と1枚ずつ照合した結果。

元データはすべて 941x1672px (9:16)。KDPの最低幅1200pxを下回るため、
Lanczos法で 1440x2560px に拡大し、ベースラインJPEG (品質92・クロマ間引きなし) で保存した。

## 画質の注意

`P01.jpg` と `P02.jpg` の元データ (001.png / 002.png) は、拡張子はPNGだが
中身はWebPで、他ページの約1/10のファイルサイズだった。
ブラウザの表示用画像を保存したものと思われ、他ページより解像感が低い。
P01は表紙の元画像にも使うため、生成元からダウンロードし直すのが望ましい。
