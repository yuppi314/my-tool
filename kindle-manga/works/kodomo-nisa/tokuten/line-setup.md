# 公式LINEの設定内容

本と同じく「制度の情報だけを届ける」に徹する。金融商品のすすめや
個別相談に踏み込むと、投資助言・代理業の登録が必要になり、
本文の免責とも矛盾する。境界はあいさつメッセージで明示している。

## プロフィール

| 項目 | 内容 |
| --- | --- |
| アカウント名 | あさひなぎさ｜家族とお金の本 |
| ステータスメッセージ | 制度のことだけ、正直に。 |
| プロフィール画像 | cover.jpg（表紙）を正方形に切ったもの |

### 説明文

『漫画でわかるこどもNISA』著者。家族とお金の決断を、漫画でわかりやすく。
こどもNISAの運用ルールが確定したときなど、制度の最新情報だけをお届けします。
金融商品のおすすめや個別のご相談は承っておりません。

## あいさつメッセージ

友だち追加した直後に自動で届く。特典画像(sheet.png)を一緒に添付する。

```
『漫画でわかるこどもNISA』を読んでくださって、ありがとうございます。
あさひ なぎさ です。

読者特典の「教育費 使う時期 仕分けシート」をお送りします。
画像を保存してお使いください。本には載せていない、書き込み式のシートです。

このアカウントからお送りするのは、次の3つだけです。

① こどもNISAの運用ルールが確定したときのお知らせ
② 制度に変更があったときのお知らせ
③ 新刊のお知らせ

金融商品のおすすめや、個別のご相談は承っておりません。
制度の情報だけをお届けします。

配信は多くても月に1〜2回です。
不要になったらブロックしてください。通知は届かなくなります。

なぎさ書房／あさひ なぎさ
```

## 2冊目を出したあと

本が増えたら、あいさつメッセージで特典を出し分けられなくなる。
そのときは自動応答（キーワード応答）に切り替える。

- 各巻の巻末に「『NISA』と送ってください」のように合言葉を書く
- キーワードごとに対応する特典を返す

いまは1冊なので、あいさつメッセージで直接渡すのが早い。
