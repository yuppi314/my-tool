# 解説パート（説明文＋図解）

漫画100ページのうしろに続く、解説パート16ページ。
並びは **漫画 → 説明文 → 図解** を8章ぶん繰り返す形。合計116ページ。

章立ては**図解にそろえてあります**（漫画の章立てとは別）。
章番号がぶつからないよう、解説パートは漫画のあとにまとめて置きます。

| 章 | テーマ |
|---|---|
| 1 | 離婚の入口 ― 気持ちの整理と最初の一歩 |
| 2 | お金の基礎知識 ― 離婚後の生活を守るために |
| 3 | 財産分与 ― もらえるお金を正しく知る |
| 4 | 年金分割 ― 将来の安心を守るために |
| 5 | 子どものこと ― 子どもの幸せをいちばんに |
| 6 | 離婚の手続き ― 流れを知って、安心して進める |
| 7 | 離婚後の生活設計 ― これからの人生を、自分らしく |
| 8 | 相談先とおわりに ― 一人で抱え込まず、未来へ |

## 説明文を作り直す

文言を直すのは `prose_text.py`。そのあと:

    python3 render_prose.py prose

1024×1536 のPNGが8枚できます。画像生成AIを使わないので、
**文字化けも数値の捏造も起きません。** 何度作り直しても同じ結果です。

## 全部つなげる

    python3 assemble.py <漫画100枚> prose <図解8枚> final

`final/0001.png` 〜 `0116.png` ができます。
枚数や番号がおかしいときは、その場で止まって何が問題か教えます。
