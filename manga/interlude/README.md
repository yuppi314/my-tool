# 章末ページ（要点・チェックリスト）16枚

各章の最後に2ページずつ入れる、図解と文章のページです。
**画像生成AIは使いません。** フォントで直接描くので、文字化けも数字の捏造も起きません。

## 作り直す

文言を変えたいときは `content.py` を直してから:

    python3 render.py pages

1024×1536 のPNGが16枚できます。何度作り直しても同じ結果になります。

## 漫画と合体させる

    python3 assemble.py <漫画100枚のフォルダ> pages final

`final/0001.png` 〜 `0116.png` ができます。この順番のままEPUBにすれば正しく並びます。

漫画のファイル名は `p001.png` でも `1.png` でも、番号が読み取れれば何でも構いません。
枚数が100枚でなかったり番号が重複していると、その場で止まって何が問題か教えます。
