# 表紙まわりの制作指示

本文はモノクロだが、**表紙だけはフルカラー**で作る。Kindleストアではサムネイルが最初の接触点になるため、
表紙は本文とは別の設計思想（＝縮小しても読めるか）で作る。

---

## 1. 表紙の仕様

| 項目 | 値 |
|---|---|
| ピクセル | **1600 × 2560px**（縦横比 1:1.6） |
| 形式 | JPEG または TIFF・RGB |
| ファイルサイズ | 50MB以下 |
| 解像度 | 300dpi推奨 |
| 最低幅 | 1000px以上（1600px推奨） |

> 表紙の推奨値はKDPの規定変更があり得る。入稿前に**KDPヘルプの最新の表紙要件を必ず確認**すること。

---

## 2. 表紙イラストの作り方（文字は後入れ）

**画像生成AIに日本語のタイトル文字を描かせない。** 必ず崩れる。
イラストだけを生成し、文字は Canva・Photopea・GIMP などで後から乗せる。

### 表紙イラスト生成プロンプト（そのまま貼る）

````

◆【絶対最優先】キャラクター外見
添付のキャラシートと100%同一の外見で描画してください。
髪色・髪型・服装・顔立ち・体型は、私の文章よりも添付画像を優先してください。
新藤みやこ＝黒の低いお団子／紺のテーラードジャケット＋白インナー／金属フレームの眼鏡あり
高橋あかり＝ライトブラウンのセミロング（毛先内巻き）／ベージュのニット＋白い襟／眼鏡なし

◆【出力サイズ】縦長 1600×2560（縦横比 1:1.6）

◆【作画】
現代日本のTVアニメ調（2010年代以降）、クリーンなデジタルセル彩色。

禁止: 厚塗り、油彩、水彩、アメコミ、3DCG、写実、劇画、モノクロ、セピア。

◆【カラー】
This must be a FULL COLOR illustration. Use vibrant, rich colors throughout.
Do NOT use grayscale, black-and-white, or monochrome.

◆【構図】
画面下半分に高橋あかりを大きくバストアップで配置。正面を向き、不安と決意の混じった表情で、

画面内に文字・ロゴ・タイトル・署名・透かしを一切描かないこと。

◆【余白】
画面上部の約35%は、後からタイトル文字を乗せるため、人物も模様も置かず、
明るい空の色だけの余白にすること。
````

## 3. 文字を乗せる（後工程）

| 要素 | 文言 | 指定 |
|---|---|---|
| メインタイトル | **漫画でわかる 離婚バイブル** | 画面上部。太めのゴシック体。白抜き＋濃い縁取り。**画面幅の80%以上**を使う |
| サブコピー | 子どもがいるママが<br>損しないための全部 | メインの直下。メインの40%程度のサイズ |
| 帯コピー | 離婚前の準備／お金／養育費／親権／離婚後の手続き | 画面下端に横帯。小さめ |
| シリーズ表記 | 漫画でわかるシリーズ | 最上部に小さく |

### サムネイル検品（必須）

作った表紙を **横160px に縮小**して眺める。これがストアでの実サイズに近い。

- [ ] 縮小しても「離婚バイブル」が読めるか
- [ ] 人物の表情が潰れていないか
- [ ] 文字と背景のコントラストが足りているか（白文字に薄い背景はNG）
- [ ] 他のひとり親向け書籍のサムネイルと並べたとき埋もれないか

## 4. キャラシートの作り方

`03_ページプロンプト集.md` の **「2. STEP 0 ／ キャラシート作成プロンプト」** に、
3体分のプロンプトが完成形で入っている。

1. SHINDO → `char_SHINDO.png`
2. TAKAHASHI → `char_TAKAHASHI.png`
3. RYOSUKE → `char_RYOSUKE.png`

**この3枚を作り終えるまで、本文ページの生成を始めないこと。**
途中でキャラシートを作り直すと、それ以前のページと外見が合わなくなる。

### キャラシートの合格基準

- [ ] 全身が切れていない（頭頂と足先が画面内）
- [ ] 顔のアップと表情差分3種が入っている
- [ ] 背景が白一色で、文字・ラベルが入っていない
- [ ] 3体を横に並べたとき、**髪のトーン**が明確に違う（ベタ黒／中間／最も淡い）
- [ ] 3体を横に並べたとき、**服のトーン**が明確に違う

モノクロ本なので、色ではなく**トーン（明暗）で区別がつくか**が唯一の基準。
ここが曖昧だと、100ページのどこかで必ず人物が入れ替わる。
