# EPUBの作り方 ― ご自分のPCで実行する手順

## なぜご自分のPCで作るのか

私（Claude）の作業環境には、次の2つの制約があります。

| 制約 | 実際に起きること |
|---|---|
| チャットに添付された画像は、**私には「見える」が「ファイルとして届かない」** | 表紙は拝見できたが、EPUBに組み込むことはできない |
| 外部サイトへの接続が**ネットワークポリシーで遮断**されている | Google Driveからの直接ダウンロードも403で拒否される |

つまり、**100枚の画像を私の環境に持ち込む方法がありません。**
そこで、役割を分けます。

| 担当 | 内容 |
|---|---|
| **Claude** | ページの目視チェック（文字化け・キャラのブレ・コマ順）／修正用プロンプトの再発行／書誌情報の作成 |
| **あなた** | 画像をEPUBにまとめる（下の3つのどれか） |

画像をチャットに貼っていただければ**中身の確認はできます**。そこが一番Claudeの価値が出るところです。

---

## 方法A：Kindle Create（おすすめ・コード不要）

Amazon公式の無料ソフト。インストールするだけで、画像フォルダからコミック形式の本を作れます。

1. KDPのサイトから **Kindle Create** をダウンロードしてインストール（Windows / Mac 両対応）
2. 起動して「新規プロジェクト」→ **コミック（Comic）** を選ぶ
3. ページ画像100枚が入ったフォルダを指定する
4. 設定で必ず次の2つを指定する
   - **綴じ方向：右から左（Right-to-Left）** ← これを間違えると全100ページが逆順になります
   - ページ表示：見開き または 単ページ
5. 「公開用に出力」で **.kpf ファイル**を書き出す
6. KDPの「原稿」に .kpf をアップロード

> 画面の項目名はバージョンで変わります。「右から左」「Right-to-Left」「日本語（縦書き・右綴じ）」
> といった表記を探してください。

**この方法だと自動で入らないもの**：章ごとの目次、免責ページ、奥付。
必要なら、それらを画像として作って100枚の前後に足してください
（免責と奥付の文面は `05_KDP登録シート.md` にあります）。

## 方法B：epub_build.py（目次・免責・奥付まで自動）

Pythonが動く環境なら、こちらのほうが仕上がりが良くなります。
**章ごとの目次・免責2ページ・奥付・Kindle向けの指定が全部自動で入ります。**

### 1. Pythonを入れる

- Windows … python.org から最新版をインストール。インストーラの
  **「Add Python to PATH」に必ずチェック**を入れる
- Mac … 最初から入っています（`python3 --version` で確認）

### 2. 必要な部品を入れる

ターミナル（Macは「ターミナル」、Windowsは「コマンドプロンプト」）で:

```
pip install Pillow
```

### 3. ファイルをそろえる

GitHubの `claude/vibrant-franklin-ltioqz` ブランチから `manga` フォルダを丸ごとダウンロードし、
その中に画像フォルダを置きます。

```
manga/
├── epub_build.py
├── spec.py / characters.py / kit.py / scenario.py / chapters/   ← 目次の生成に使う
└── pages/        ← ここに100枚を入れる
```

### 4. まず検査する

```
cd （mangaフォルダのパス）
python3 epub_build.py --check pages
```

枚数・サイズの不揃い・番号の重複や欠番を教えてくれます。ここで出た問題を直してから次へ。

### 5. EPUBを作る

```
python3 epub_build.py pages --cover cover.png --pubdate 2026年10月1日
```

`out/divorce_bible.epub` ができます。これをKDPの「原稿」にアップロードします。

ファイル名は自由です。**名前に含まれる数字**で順番を決めるので、
`p001.png` でも `1.png` でも `ページ01.jpg` でも構いません。

## 方法C：でんでんコンバーター（ブラウザだけ）

インストールしたくない場合。無料のWebサービスで、画像ZIPから固定レイアウトEPUBを作れます。

1. 画像100枚を**連番にしてZIP**にまとめる（`p001.png`〜`p100.png` のように3桁ゼロ埋め）
2. でんでんコンバーターのサイトでZIPをアップロード
3. 設定で **「右綴じ」** と **「固定レイアウト（画像のみの本）」** を選ぶ
4. 出てきたEPUBをKDPにアップロード

---

## どの方法でも、最後に必ずやること

**Kindle Previewer**（Amazon公式・無料）で開いて確認します。

- [ ] 1ページ目から最後まで、抜け・重複・順番違いがないか
- [ ] **ページが右から左へめくれるか** ← 最重要。逆だと全ページ読み順が壊れます
- [ ] スマホ表示で吹き出しの文字が読めるか
- [ ] 表紙が正しく表示されるか

ここが通れば、KDPにアップロードして出版できます。

## 画像を小さくしたいとき

生成AIが出す1024×1536のPNGは1枚1.5〜2.5MBあります。100枚で200MB前後。
**JPEG（画質85〜90）に変換すると1枚300〜500KBまで落ちます。**
見た目はほとんど変わらず、KDPの配信コストが下がってロイヤリティの手取りが増えます。

- Mac … 全選択 → 右クリック → 「イメージを変換」 → JPEG
- Windows … XnConvert などの一括変換ソフト

※ `epub_build.py` は内部で自動的にJPEG変換するので、方法Bなら事前変換は不要です。
