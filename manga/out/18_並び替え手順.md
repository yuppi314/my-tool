# 解説・図解を章ごとに挟む（改訂版の作り方）

出版後でも、KDPの本棚から「電子書籍の内容を更新」で原稿だけ差し替えられます。
レビュー・ランキング・商品URLはそのまま引き継がれます。

## 変わること

旧：漫画1〜100 →（最後にまとめて）解説8＋図解8 → 巻末2
新：漫画（章）→ 解説 → 図解 → 漫画（次の章）→ … → 巻末2

総ページ数は119枚（巻末に「著者の他の本」を1枚追加）。

解説の番号が章番号とずれているのは、解説が図解8枚のテーマに合わせて
書かれているためです。中身が合う章のうしろに置いています。

章番号どおり（解説1→第1章、解説2→第2章…）に並べたい場合は、
assemble.py の上のほうにある `MODE = "theme"` を `MODE = "even"`
に書き換えてから実行してください。

## 手順（Windows）

作業フォルダで、順に1行ずつ実行します。

    cd /d C:\Users\mikoc\OneDrive\デスクトップ\離婚バイブル

    rmdir /s /q out

    python assemble.py manga 解説 図解 out back

「118 枚を out/ に並べました。（並べ方: theme）」と出て、
0015 解説1 / 0027 解説6 … と一覧が出れば成功です。

    python epub_build.py out --cover cover.jpg --out "%USERPROFILE%\divorce_bible.epub"

できた divorce_bible.epub を、KDPの本棚 →「…」→
「Kindle 電子書籍の内容を更新」→ 原稿を差し替え → 保存して続行 →
価格の画面まで進んで「変更内容を公開」。

反映までは数時間〜72時間です。
