# 出版までの手順

上から順にやれば終わります。**所要 3〜4時間**（審査待ちを除く）。

---

## ステップ1　漫画のフォルダを100枚ちょうどにする

ここが一番の落とし穴です。

- [ ] 引き直した**古いほうの画像を削除**
      （12・21・27・32・40・43・46・96・13・54・56・18・79・83）
- [ ] **扉絵9枚のモノクロ版**が残っていないか確認
      カラーであるべきページ → **P1・P3・P15・P25・P37・P51・P65・P77・P89**
- [ ] フォルダの枚数を数える → **ちょうど100枚**

ファイル名は `p001.png` でも `1.png` でも構いません。番号が読み取れて重複していなければOKです。

---

## ステップ2　116枚に並べる

`解説パート.zip` を展開して、その中で実行します。

```
python3 assemble.py <漫画100枚のフォルダ> prose <図解8枚のフォルダ> final
```

`final/0001.png` 〜 `0116.png` ができます。
枚数や番号がおかしいときは、その場で止まって何が問題か教えてくれます。

**図解8枚のファイル名は、章番号が読み取れるようにしてください**（`zukai1.png`〜`zukai8.png` など）。

---

## ステップ3　EPUBにする

同じ場所で実行します。Pythonと Pillow が必要です。

```
pip install pillow
python3 epub_build.py --check final
python3 epub_build.py final --cover cover.png --pubdate "2026年10月1日"
```

`out/divorce_bible.epub` ができます。
**右綴じ・固定レイアウト・目次・免責・奥付まで自動で入ります。**

> `--check` は検査だけして終わります。ここで止まったら、ステップ1か2に戻ってください。

---

## ステップ4　表紙を確認する

- [ ] **1600×2560px** になっているか（違えばリサイズ）
- [ ] JPGまたはTIFF
- [ ] タイトルがスマホのサムネイルサイズで読めるか

---

## ステップ5　Kindle Previewer で検品

Amazon公式の無料ソフトです。ここを飛ばすと事故ります。

- [ ] **ページが右から左へめくれるか** ← 最重要
- [ ] 1ページ目から116ページ目まで、抜け・重複・順序違いがないか
- [ ] スマホ表示で吹き出しの文字が読めるか
- [ ] 解説パート（101〜116）が漫画のあとに続いているか

---

## ステップ6　KDPに登録

`05_KDP登録シート.md` を開いて、上から順にコピペします。
タイトル・内容紹介・キーワード7枠・カテゴリーまで、そのまま貼れる形で書いてあります。

- [ ] 原稿：`divorce_bible.epub`
- [ ] 表紙：`cover.jpg`（1600×2560px）
- [ ] 価格：¥1,000（ロイヤリティ70%）
- [ ] KDPセレクト：登録する（Kindle Unlimited の読み放題に入る）

審査は**通常72時間以内**、多くは24時間ほどで終わります。

---

## 出したあとに直すこと（急ぎません）

KDPは**出版後も何度でも無料でファイルを差し替えられます。** 以下は売りながら直せます。

| | 内容 |
|---|---|
| 図解 第1章 | A・B・Cが漫画と逆（A＝迷い／C＝危険）。図解を1枚作り直せば直ります |
| 漫画 法改正5枚 | P24・P49・P57・P64・P71。内容は間違っていませんが最新ではありません |
| 漫画 推奨4枚 | P28・P34・P44・P48。図の見やすさの問題で、読めます |

差し替えたら、内容紹介に「2026年4月施行の民法改正に対応」を足すと強くなります。
