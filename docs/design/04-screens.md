## Version 0.1 画面一覧

| 画面ID | 画面名 | 目的 | 主要機能 | 初回起動時の表示 |
|---|---|---|---|---|
| S01 | オンボーディング | 初回起動時のセットアップ | ライセンスキー入力、会社情報入力 | ○(初回のみ) |
| S02 | ダッシュボード | 見積書の一覧・入り口 | 見積書一覧表示、新規作成、検索 | 2回目以降の起動時 |
| S03 | 見積書エディタ | 見積書の作成・編集 | 品目入力、自動計算、AI対話パネル、PDFプレビュー/保存 | - |
| S04 | 顧客一覧 | 顧客管理の入り口 | 顧客一覧表示、検索、新規登録導線 | - |
| S05 | 顧客登録/編集(モーダル) | 顧客情報の登録・編集 | 氏名/会社名・住所・連絡先の入力 | - |
| S06 | 会社情報設定 | 自社情報の登録・編集 | ロゴ・住所・振込先等 | オンボーディングと共通 |
| S07 | 設定画面 | 各種設定の集約 | タブ: AI設定/バックアップ/ライセンス/ヘルプ | - |
| S08 | フィードバック送信(モーダル) | 要望・不具合報告 | メールクライアント起動 | - |

## 画面とVersion 0.1機能の対応

| 機能(要件定義9番) | 対応画面 |
|---|---|
| 会社情報登録 | S01, S06 |
| 顧客管理 | S04, S05 |
| 見積書作成 | S02, S03 |
| AI入力補助 | S03(AI対話パネル) |
| PDF出力 | S03 |
| データのエクスポート/インポート | S07(バックアップタブ) |

## 補足

- S03(見積書エディタ)がアプリの中核画面であり、最も設計・実装の比重が大きい
- PDFプレビューは独立画面ではなく、S03内のパネル/モーダルとして統合する(画面遷移を増やさずMVPをシンプルに保つ方針)
