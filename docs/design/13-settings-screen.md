## 構成

設定画面(S07)は左側にタブ、右側に各タブの内容を表示するレイアウトとします([06. ワイヤーフレーム](./06-wireframes.md)参照)。

| タブ | 主な項目 |
|---|---|
| 会社情報 | 会社名、ロゴアップロード、住所、電話番号、振込先情報、[保存] |
| AI設定 | プロバイダー選択(Claude/OpenAI/Gemini)、APIキー入力欄(マスク表示)、[保存][削除][接続テスト]、未設定時の案内文言 |
| バックアップ | [エクスポート]ボタン、[インポート]ボタン(ファイル選択)、最終バックアップ日時の表示 |
| ライセンス | ライセンスキー入力欄、認証状態表示、[認証する]ボタン |
| ヘルプ・フィードバック | [フィードバックを送る]ボタン([16.フィードバック送信設計](./16-feedback.md)へ)、アプリバージョン表示 |

## 補足

- 「AI設定」タブは、APIキーが未設定の場合にタブ横へ軽いバッジ(例: ●)を表示し、設定漏れに気づきやすくする(ワイヤーフレーム参照)
- 「バックアップ」タブはMVPの必須機能であるため、初回起動後にダッシュボードや設定画面内で「まだバックアップを取っていません」という控えめなリマインドを表示することを検討する(強制はしない)
- 各タブの保存操作は即座に反映し、アプリ再起動を要求しない設計とする
