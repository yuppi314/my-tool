# Kindle本 企画・構成案(第1弾)

目的は**本で稼ぐことではなく、読者を公式LINEに集めること**。Kindle Unlimited(読み放題)に登録し、読まれた分だけ印税を受け取りながら、巻末特典でLINEに誘導する。

---

## 1. コンセプト

| 項目 | 案 |
|---|---|
| 読者 | 50代女性。子育てや仕事が一段落し、「これからの人生、何か変えたい」と思っている人。占いは好きだが九星気学は詳しくない |
| 約束すること | 「旅行するだけで運気を整える」吉方位旅の始め方が、1冊で全部わかる |
| 他の本との違い | 九星気学の入門書は多いが、**マイルを使ってお得に吉方位へ行く**ところまで書いた本はほぼない |
| 分量 | 約2〜3万字(1〜2時間で読み切れる長さ。Unlimitedで最後まで読まれると印税が多くなる) |
| 価格 | 発売直後の1週間は99円 → その後は500円(Unlimitedでは無料で読める) |

### タイトル案
1. **『50代からの開運旅 ― 九星気学の吉方位とマイルで、人生の流れを変える』**(第一候補)
2. 『旅するだけで運が整う ― はじめての吉方位旅行』
3. 『マイルで行く吉方位旅 ― 50代、もう一度人生を楽しむための九星気学』

サブタイトルに「九星気学」「吉方位」「50代」を入れて、Amazonの検索に引っかかるようにする。

## 2. 目次案

**はじめに ― なぜ50代から「旅」で運気を整えるのか**
- 著者の体験談(なぜ吉方位旅を始めたか)
- ▶ LINE誘導①:「本書の特典は巻末にあります」

**第1章 九星気学のきほん**
- 本命星の調べ方(早見表つき)
- 9つの星の性格(一白水星〜九紫火星)
- 「立春から1年」「節入りから1か月」という暦の考え方
- ▶ 章末:「ご自宅から見た今月の吉方位は、公式LINEで無料診断できます」

**第2章 吉方位とは何か**
- 年盤・月盤と「最大吉方」
- 凶方位(五黄殺・暗剣殺・本命殺・本命的殺・破)
- 八方塞がりの年・月の過ごし方
- 方位ごとの運気(北=信頼・愛情 … 北西=仕事運・引き立て)

**第3章 吉方位旅のルール**
- 自宅から100km以上離れる/滞在のしかた
- 温泉・食事・お水取りなど「気をいただく」行動
- 方位の測り方(地図で測るとズレる理由)

**第4章 マイルでお得に吉方位へ**
- 50代から始めるマイルの貯め方(日々の買い物・カード)
- 特典航空券の取り方とコツ(取りやすい時期・路線)
- 東京・大阪・福岡発のモデルコース
- ▶ ここで紹介するカード・予約サイトのリンクは、本ではなく**LINEで案内する**(本文にアフィリエイトリンクは載せない)

**第5章 吉方位旅のモデルプラン(9つの星別)**
- 星ごとに「向いている旅のしかた」と旅先の例
- ▶ 章末:「2027年のあなたの吉方位カレンダーはLINEでプレゼント」

**おわりに ― 旅は、人生の流れを自分で選ぶこと**

**【読者限定プレゼント】(巻末・1ページ)**
- 2027年 本命星別 吉方位カレンダー(PDF)
- ご自宅から見た今月の吉方位がわかる無料診断
- 公式LINEを友だち追加して「開運旅」と送るだけ(URLとQRコードを掲載)

## 3. LINE誘導のルール(KDPの規約を守る)

- 外部リンク・特典の案内は**OK**
- 「レビューを書いたら特典」は**NG**(Amazonの規約違反で、本が削除されることがある)
- 本文中にアフィリエイトリンクを貼るのは避ける(紹介はLINEで行う)
- 「必ず運が良くなる」などの断定は避け、「〜とされています」と書く
- 冒頭に「九星気学は流派によって解釈が異なる」旨を一文入れる

## 4. 表紙のイメージ

SNSと同じ**夜空 × 金 × 明朝体**のデザインにそろえて、SNSで見た人が「あの人の本だ」とすぐわかるようにする。
- 紺の星空の背景に、金の円(方位盤のモチーフ)
- タイトルは明朝体、「開運旅」だけ金色で大きく
- 下の方に小さく旅のシルエット(飛行機・温泉など)

表紙画像(1600x2560)は `night-reel.js` と同じデザインで生成できる。
