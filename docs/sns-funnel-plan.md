## 1. 全体の導線(すべて公式LINEに集める)

```
 Instagram / Threads / X        Kindle本(冒頭・各章末・巻末)
          │                              │
          └──────► 公式LINE(友だち追加特典) ◄──┘
                         │
     ┌───────────────────┼────────────────────┐
     ▼                   ▼                    ▼
 吉方位ツール(無料診断)  鑑定書(個別・有料)     アフィリエイト
 → 月額¥480/買切¥980     → 単発¥3,980〜         マイルカード/宿/航空券
```

**なぜLINEに集めるか**: SNSはアルゴリズム次第で届かなくなるが、LINEは「毎月の吉方位」という自然な配信理由で、月1回以上確実に届く。販売はすべてLINEで行い、SNSは「信頼づくり+LINE誘導」に専念する。

### LINE友だち追加特典(これが最重要)
- **特典A**: 「本命星別・今月の吉方位カード」(9種類の画像。`scripts/sns-map.js` で自動生成済みのものを流用)
- **特典B**: 生年月日を送ると本命星と今月の最大吉方を返信(リッチメニューから吉方位ツールへ)
- **特典C(Kindle読者限定)**: 合言葉「開運旅」で、本に載せきれなかった「2027年 吉方位カレンダー」PDF

### LINE配信スケジュール(月4回まで=無料枠に収める)
| 時期 | 内容 | 目的 |
|---|---|---|
| 節入り2日前 | 来月の吉方位まとめ(9星) | 開封習慣づくり |
| 節入り当日 | 今月の吉方位 + 旅先例 + ツールリンク | ツール登録 |
| 月中 | 旅の準備(マイルカード・宿)※PR表記 | アフィリエイト |
| 月末 | 鑑定書の案内(先着◯名・期限つき) | 販売 |

### 商品ラインナップ(提案)
| 商品 | 価格 | 中身 |
|---|---|---|
| 吉方位ツール(無料) | 0円 | 今月の最大吉方・旅先3件 |
| 吉方位カレンダー | 月額480円 / 買切980円 | 12ヶ月分(実装済み) |
| 開運旅 鑑定書 | 3,980円 | 本命星・月命星の性格、1年の吉方位、おすすめ旅先、注意月をPDFで |
| 鑑定書プレミアム | 9,800円 | 上記+家族分+LINEで質問1回 |

## 5. 守るべきルール(アカウントBANと炎上の防止)

- **PR表記**: アフィリエイトリンクを含む投稿・LINE配信には必ず「PR」「広告」を明記(ステマ規制・2023年10月〜)
- **断定しない**: 「必ず運が良くなる」「病気が治る」「お金が増える」はNG。「〜とされています」「〜がおすすめ」に言い換える
- **Amazonアソシエイト**: SNS・ブログはOK。LINE配信やメールでのアソシエイトリンクは規約上NGなので、LINEでは通常のAmazonリンクにする
- **鑑定書の販売**: 特定商取引法の表記(`public/tokushoho.html`)を事業者情報で埋めてから販売開始
- **娯楽目的の免責**: プロフィールかLINEのあいさつ文に一文入れる
