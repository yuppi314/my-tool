# 個人事業主 開業支援ツール 要件提示書

## 1. 概要

会社員などから個人事業主として開業する本人(自分専用)が、開業に必要な手続きを漏れなく進められるように支援するWebツール。
「何を」「いつまでに」「どこへ」提出・実施する必要があるかを可視化し、タスクの進捗を管理できることを目的とする。

## 2. 背景・課題

- 開業手続きは提出先(税務署・年金事務所・年金基金・銀行・自治体など)と期限がバラバラで、抜け漏れが起きやすい。
- 「開業届」「青色申告承認申請書」など、書類ごとに提出期限の起算日が異なる(例: 開業届は開業日から1か月以内、青色申告承認申請書は原則2か月以内)。
- 退職時期・開業時期によってタスクの要否が変わる(例: 会社員から独立する場合のみ国民健康保険・国民年金の切替が必要)。

## 3. スコープ

### 3.1 対象に含む

- 開業前〜開業後1〜2か月程度に発生する定型的な手続きのタスク化・進捗管理
- 開業届・青色申告承認申請書など主要書類の入力支援(入力補助・下書き保存・PDF出力)
- 提出期限の自動計算とリマインド表示
- 手続きの実施状況(未着手/進行中/完了)の一覧管理

### 3.2 対象外(スコープ外)

- 実際の税務署・年金事務所等へのオンライン提出(e-Tax等)との自動連携
- 日々の記帳・仕訳や確定申告書類の作成(会計ソフトの代替)
- 複数ユーザーでの共有・アカウント管理(自分専用のため認証は簡易なもので可)
- 法人化(法人設立)に関する手続き

## 4. 想定利用者

- 本人1名(自分専用ツール)。マルチユーザー機能は不要。

## 5. 機能要件

### 5.1 開業診断・初期設定

- 開業日(予定含む)、直前の状況(会社員/学生/フリーランス継続など)、青色申告を希望するか、を入力する初期設定画面。
- 入力内容に応じて、必要なタスク一覧を自動生成する(該当しないタスクは非表示または対象外表示)。

### 5.2 タスク・進捗管理機能

- タスク一覧をカテゴリ別(税務署/社会保険・年金/銀行/自治体/その他)に表示。
- 各タスクは以下のステータスを持つ: 未着手 / 進行中 / 完了。
- 各タスクに期限日を自動計算して表示し、期限が近い(例: 7日以内)ものを強調表示。
- タスクの並び替え・フィルタ(ステータス別・カテゴリ別・期限順)。
- 全体の進捗率(完了タスク数/全タスク数)をダッシュボードに表示。
- 任意でメモを残せる(例: 「〇月〇日に税務署へ持参予定」)。

### 5.3 主要書類の作成支援

対象書類(初期スコープ):

1. 個人事業の開業・廃業等届出書(開業届)
2. 所得税の青色申告承認申請書
3. (該当者のみ)青色事業専従者給与に関する届出書
4. (該当者のみ)給与支払事務所等の開設届出書

機能:

- 各書類ごとの入力フォーム(氏名・住所・屋号・事業内容・開業日など共通項目は使い回し)。
- 入力内容から下書きを保存(ブラウザを閉じても再開できる)。
- 入力内容を印刷用レイアウト(PDF or 印刷用HTML)として出力し、手書き転記や税務署窓口提出に使えるようにする。
- 各書類の提出期限・提出先を画面内に明記する。

### 5.4 手続きガイド・リマインド

- 各タスクに「何をすべきか」「提出先」「持ち物・必要書類」の簡単な説明を付与。
- 期限超過・期限間近のタスクをダッシュボードのトップに表示。
- (将来拡張)ブラウザ通知やメール通知でのリマインド。初期版はアプリ内表示のみで可。

## 6. 非機能要件

- **利用環境**: PC・スマートフォンのブラウザで閲覧・入力可能なレスポンシブデザイン。
- **認証**: 自分専用のため、簡易なパスワード保護(既存admin.htmlのトークン方式を踏襲)で十分。複雑な会員登録機能は不要。
- **データ保存**: 入力データ(初期設定・タスク状況・書類下書き)はサーバー側に永続化し、ブラウザを変えても引き継げること。
- **法的正確性**: 表示する提出期限・提出先等の情報は、あくまで一般的な目安である旨を明記し、正式な手続きは税務署・年金事務所等の公式情報で確認するよう注意書きを入れる(本ツールは正式な提出代行や税務相談ではない)。
- **保守性**: 手続き内容(期限のルールや書類項目)は法改正等で変わりうるため、タスク定義・書類項目はコード内の設定ファイルで一元管理し、修正しやすくする。

## 7. 画面構成(案)

| 画面 | 内容 |
|---|---|
| 初期設定画面 | 開業日・直前の状況・青色申告希望の有無などを入力 |
| ダッシュボード | 進捗率、期限が近いタスク、カテゴリ別タスク件数のサマリー |
| タスク一覧画面 | カテゴリ・ステータス・期限でのフィルタ、ステータス変更、メモ入力 |
| 書類作成画面(書類ごと) | 入力フォーム、下書き保存、印刷/PDF出力 |
| 設定画面 | 開業日等の初期設定値の再編集 |

## 8. データモデル(案)

- `profile`: 氏名、住所、屋号、事業内容、開業日、直前の状況、青色申告希望フラグ
- `tasks`: id、カテゴリ、タイトル、説明、提出先、期限日、ステータス、メモ、表示要否フラグ
- `documents`: id、書類種別、入力内容(JSON)、下書き保存日時

## 9. 技術方針(案)

- 既存リポジトリ構成(Node.js + Express + SQLite + 素のHTML/CSS/JS)を踏襲し、新規ツールとして追加する想定。
- 既存の九星気学×マヤ暦診断ツールとは無関係の別機能として、ルーティング・画面を分離する。
