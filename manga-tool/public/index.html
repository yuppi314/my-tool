4. PDFを書き出す

KDPペーパーバック向けの判型(デフォルト6×9インチ)でPDFを生成します。Kindle電子書籍化の手順は下記を参照してください。

PDFをダウンロード
Kindle出版までの流れ
  1. ペーパーバック(紙の本): このPDFをそのまま KDP の「原稿」としてアップロードできます(表紙は別途 KDP のカバー作成ツールか自作のPDF/画像を用意してください)。
  2. Kindle電子書籍(固定レイアウト): 漫画のKindle化には Amazon の Kindle Comic Creator / Kindle Create などの専用ツールでのパッケージングが必要です。本ツールが生成する各ページのSVG/PDFを画像化してそれらのツールに読み込ませてください。
  3. 解像度や余白の要件は KDP のガイドラインに従って `.env` の PDF_TRIM_WIDTH_IN / PDF_TRIM_HEIGHT_IN を調整してください。
