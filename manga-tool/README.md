# Kindle漫画 制作ツール

Kindle(KDP)で漫画を出版するための制作管理ツールです。1冊分の漫画づくりに必要な要素をひとつのワークスペースにまとめています。

## できること

| タブ | 内容 |
|---|---|
| 基本情報 / KDP | タイトル・著者・判型・紹介文・KDPカテゴリ/検索キーワードの下書き |
| キャラクター | 名前・外見・性格・口調・テーマカラー・参照画像を記録し、話をまたいだ**キャラの絵柄・設定のブレを防止** |
| 章立て・シナリオ | 章の並べ替え(▲▼)・進行ステータス(プロット/シナリオ/ネーム/完成)管理、シーン単位のセリフ・ト書き台本を作成 |
| コマ割り | ページごとに「1コマ/2分割/3分割/4〜8分割」等のテンプレートを適用し、各コマをドラッグで移動・リサイズ。コマごとにショット種別・内容・セリフ・登場キャラを登録するネーム作成ツール |
| はじめに・おわりに | 巻頭・巻末ページの原稿を作成 |
| 目次・書き出し | 章立てから目次を自動生成し、キャラ設定・シナリオ・コマ割り・はじめに/おわりを1冊分の「制作資料」として画面表示。印刷(PDF保存)・HTMLダウンロードに対応 |

画像生成(作画)は行いません。プロット固めからネーム(コマ割り)設計、原稿執筆、KDP出稿情報の整理までの**制作進行を支援するツール**です。

## セットアップ(自分のPCで動かす場合)

```bash
cd manga-tool
npm install
npm start
```

`http://localhost:3100` にアクセスすると作品一覧画面が開きます。

- データは `data/app.db` (SQLite) に保存されます。
- 環境変数は `.env.example` を参考に `.env` を作成してください(`PORT` のみ)。

## スマホ・タブレットから使う(インターネット公開)

このツールはNode.jsサーバーなので、スマホ単体では起動できません。スマホから使うには、無料の
[Render.com](https://render.com) にデプロイして公開URLを発行するのが簡単です。

1. Render.comにGitHubアカウントで無料サインアップ(カード登録不要)。
2. 「New +」→「Blueprint」→ このリポジトリを選択。
3. リポジトリ直下の `render.yaml` に `kindle-manga-tool` サービスが定義済みなので、そのまま作成すればOK。
4. 数分後に発行されるURL(例: `https://kindle-manga-tool.onrender.com`)をスマホのブラウザで開けば使えます。

> 無料プランは永続ディスクが使えないため、Renderの再起動でデータがリセットされる点に注意してください。
> 継続的に使う場合は Docker + 永続ディスク構成(`Dockerfile` あり)に切り替えてください。

コマ割りエディタのドラッグ・リサイズはPointer Eventsで実装しているため、マウスだけでなく
スマホ・タブレットのタッチ操作にも対応しています。

## ディレクトリ構成

```
manga-tool/
  src/
    server.js          Expressサーバー起動
    db.js               SQLiteスキーマ初期化
    routes/
      projects.js        作品(プロジェクト)CRUD・KDPメタ情報
      characters.js       キャラクター設定CRUD
      chapters.js          章立てCRUD・並べ替え
      scenes.js             シナリオ(シーン台本)CRUD
      pages.js               コマ割り(ページ・コマ)CRUD・テンプレート適用
      frontmatter.js          はじめに/おわりにCRUD
      export.js                目次込みの制作資料HTMLを組み立てて返す
  public/
    index.html / project.html  フロントエンド(素のHTML/CSS/JS、ビルド不要)
    js/*.js                     タブごとのロジック(キャラクター/章立て/コマ割り 等)
```

## コマ割り(ネーム)エディタについて

- ページを追加すると初期テンプレート(4分割)が適用されます。
- テンプレートパレットから「1コマ(見開き)/横2分割/縦2分割/3分割/4分割/6分割/8分割」をワンクリックで適用可能。
- 各コマは枠をドラッグで移動、右下のハンドルでリサイズできます(位置・サイズはページに対する%で保存)。
- コマを選択すると右側のフォームで「ショット種別・内容(構図メモ)・セリフ・登場キャラクター」を編集できます。

## 書き出しについて

「目次・書き出し」タブで、以下を1つのドキュメントにまとめて表示します。

1. 表紙情報(タイトル・著者)
2. 目次(章立てから自動生成、ページ表記は章ごとに手入力可能)
3. はじめに
4. キャラクター設定一覧
5. 各章のシナリオ + コマ割り図
6. おわりに
7. KDP出版メタ情報(紹介文・カテゴリ・キーワード)

ブラウザの印刷機能でPDF保存するか、単体のHTMLファイルとしてダウンロードして監修者・作画担当と共有できます。
