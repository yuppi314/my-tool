# AI漫画作成ツール

プロット(あらすじ)から漫画を作るツールです。**シナリオ生成**(セリフ・コマ割りなどのテキスト)と
**漫画生成**(コマ絵・吹き出し合成・PDF書き出し)を明確に分離したパイプラインになっています。

```
プロット
  ↓ (Claude API — シナリオ生成)
構造化シナリオ (タイトル/キャラクター/ページ/コマ/セリフ/キャプション/効果音)
  ↓ (人が編集可能)
  ↓ (画像生成プロバイダ — コマごとの絵)
コマ絵 + レイアウト計算 + 吹き出し合成 (SVG)
  ↓
プレビュー(ブラウザ) / PDF書き出し(KDP入稿用)
```

## できること

- **シナリオ生成**: プロットとページ数を入力すると、Claude がページ・コマ割り・セリフ・キャプション・効果音まで含めた漫画のネームを生成します。
- **編集**: 生成されたシナリオはブラウザ上で全項目編集できます(画像生成前に何度でも無料で修正可能)。
- **漫画生成**: コマごとに画像生成プロバイダを呼び出し、レイアウト計算・吹き出し・キャプションと合成してページを作ります。
  - デフォルトの `placeholder` プロバイダはAPIキー不要で、色分けされたパネル+セリフ吹き出しの「ネーム(下書き)」を出力します(構成・セリフの確認用)。
  - `IMAGE_PROVIDER=openai` を設定すると OpenAI Images API で実際のイラストを生成します。
- **PDF書き出し**: KDPペーパーバック向けの判型(デフォルト6×9インチ)でPDFを書き出せます。

## セットアップ

```bash
npm install
cp .env.example .env
# .env に ANTHROPIC_API_KEY を設定
npm start
```

`http://localhost:3001` にアクセスしてください。

## Kindle出版までの道のり

1. **ペーパーバック(紙の本)**: このツールが生成するPDFをそのまま KDP の原稿としてアップロードできます。表紙は別途用意してください(KDPのカバー作成ツール、または自作のPDF)。
2. **Kindle電子書籍(固定レイアウト)**: 漫画をKindleの電子書籍として出す場合、Amazonの Kindle Comic Creator や Kindle Create など専用ツールでのパッケージングが別途必要です(このツールのAPIでは自動化できない手作業のステップです)。本ツールで生成した各ページのSVG/PDFを画像として書き出し、それらのツールに読み込ませてください。
3. 判型・解像度はKDPのガイドラインに合わせて `.env` の `PDF_TRIM_WIDTH_IN` / `PDF_TRIM_HEIGHT_IN` を調整してください。

## アーキテクチャ上の分離

- `src/lib/scenario.js` — シナリオ生成のみを担当。画像生成には一切関知しない。
- `src/lib/imageProvider.js` — コマ単位の画像生成を抽象化。プロバイダの差し替えが容易。
- `src/lib/layout.js` — コマ数からページレイアウト(矩形)を計算する純粋関数。
- `src/lib/composeSvg.js` — レイアウト・画像・セリフ・キャプションを1枚のSVGに合成する。ブラウザプレビューとPDF出力の両方がこの単一の関数を共有する。
- `src/lib/pdfExport.js` — SVGをPDFページに変換して束ねる。

この分離により、シナリオだけを何度も安く作り直したり、画像生成プロバイダだけを差し替えたりできます。

## 既知の制約(v1)

- 読み順は左上から右下へ(西欧式)です。伝統的な右から左への日本式コマ送りには未対応です。
- `placeholder` プロバイダは実際のイラストを生成しません(構成確認用の色付きパネルのみ)。
- 吹き出しのしっぽは左右交互に出す簡易ロジックです。実際のキャラクターの立ち位置(画像内の座標)を認識して指すものではありません。
